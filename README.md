# GB7 Studio

Веб-приложение для пяти лабораторных работ по цифровому представлению, анализу, коррекции, масштабированию и фильтрации изображений.

## Возможности

- загрузка PNG, JPG/JPEG и учебного формата GrayBit-7;
- отрисовка изображения в HTML5 Canvas без библиотек обработки изображений;
- собственные декодер и кодер GB7 версии 1;
- скачивание текущего изображения в PNG, JPG или GB7;
- двоичная маска прозрачности GB7;
- отображение ширины, высоты, глубины цвета, формата и размера файла;
- панель каналов с миниатюрами и независимым включением компонентов;
- поддержка моделей Gray, Gray + Alpha, RGB и RGBA;
- просмотр альфа-канала как чёрно-белой маски;
- пипетка с координатами пикселя, RGB, HEX и CIELAB;
- диалог «Уровни» с общей и поканальными гистограммами;
- линейный и логарифмический режимы гистограммы;
- отдельные настройки уровней для Master, цветовых каналов и Alpha;
- точки чёрного и белого, гамма от 0.1 до 9.9 и предпросмотр результата;
- собственные реализации ближайшего соседа и билинейной интерполяции;
- экранный масштаб от 12% до 300%, режимы «вписать» и 1:1;
- изменение ширины и высоты изображения в пикселях или процентах;
- свёртка с пользовательским ядром 3×3 и обработкой отдельных каналов;
- размытие по Гауссу, прямоугольное размытие, резкость и операторы Прюитта;
- медианный фильтр 3×3 и три стратегии заполнения края;
- фоновая обработка больших изображений без блокировки интерфейса;
- drag-and-drop, горячие клавиши `Ctrl/Cmd + O`, `Ctrl/Cmd + S`, `I`, `L`, `R` и `F`;
- адаптивный интерфейс для узких и широких экранов.

## Запуск

Проект не требует установки зависимостей. Для работы со своими изображениями можно открыть `index.html` двойным щелчком.

Чтобы встроенные примеры загружались одной кнопкой, запустите локальный статический сервер из корня проекта:

```bash
python3 -m http.server 8080
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Реализация GrayBit-7

Кодек находится в `js/gb7.js`.

- Проверяются сигнатура `47 42 37 1D`, версия, флаги, размеры, резервное поле и длина данных.
- Ширина и высота читаются и записываются в big-endian порядке.
- При декодировании значение `0…127` переводится в `0…255`.
- При кодировании RGB переводится в яркость по формуле Rec. 709: `0.2126R + 0.7152G + 0.0722B`.
- Если есть прозрачные пиксели, устанавливается флаг маски. Альфа `0…127` считается прозрачной, `128…255` — непрозрачной.
- При отсутствии маски старший бит каждого пикселя равен нулю.

PNG и JPEG декодируются и кодируются средствами браузера. Их заголовки читаются отдельно для показа исходной глубины цвета.

## Цветовые каналы

После загрузки исходные RGBA-пиксели один раз копируются в отдельный неизменяемый буфер. Переключение каналов создаёт новый массив для вывода на основной canvas и не меняет оригинал.

- Gray: один канал яркости;
- Gray + Alpha: яркость и прозрачность;
- RGB: красный, зелёный и синий каналы;
- RGBA: RGB и альфа-канал.

Миниатюры отдельных каналов показываются в градациях серого. Если в RGBA или Gray + Alpha оставить только альфа-канал, основной canvas показывает непрозрачную чёрно-белую маску.

## Пипетка и CIELAB

Пипетка включается кнопкой на левой панели или клавишей `I`. Координаты клика пересчитываются из CSS-размера canvas в реальные координаты изображения, поэтому инструмент работает при любом масштабе.

Пипетка читает RGB исходного пикселя. Для перевода sRGB в CIELAB сначала выполняется линеаризация компонентов, затем переход в XYZ с белой точкой D65 и расчёт `L*`, `a*`, `b*`.

## Уровни и гистограмма

Инструмент открывается кнопкой на левой панели или клавишей `L`. Диалог построен на HTML-элементе `<dialog>`. Для Master гистограмма рассчитывается по относительной светимости W3C после линеаризации sRGB, для Red, Green, Blue, Gray и Alpha используются значения выбранного канала. Доступны линейная и логарифмическая шкалы.

Для PNG и JPEG строится 256 столбцов, для GB7 используется диапазон `0…127`. Точки чёрного и белого ограничивают друг друга, а маркер гаммы всегда остаётся между ними. Настройки каждого канала сохраняются при переключении списка.

Коррекция выполняется через таблицы подстановки LUT. Предпросмотр обновляется через `requestAnimationFrame` и не изменяет исходный массив пикселей. Флажок «Предпросмотр» показывает изображение до открытия инструмента, кнопка «Сбросить» возвращает начальные параметры, «Отмена» закрывает окно без изменений, а «Применить» сохраняет результат в новый буфер.

## Масштабирование изображения

Оба метода интерполяции реализованы вручную в `js/interpolation.js`. Метод ближайшего соседа выбирает один исходный пиксель для каждой новой координаты. Билинейный метод вычисляет взвешенное среднее четырёх соседних пикселей отдельно для каналов RGBA. Модуль хранит методы в общем реестре, поэтому в него можно добавить новые алгоритмы.

Основной canvas перерисовывается собственным алгоритмом, а не масштабируется средствами CSS. Диапазон просмотра составляет от 12% до 300%. При загрузке вычисляется масштаб, который оставляет вокруг изображения отступы по 50 px, после чего значение ограничивается разрешённым диапазоном.

Окно «Размер изображения» открывается кнопкой в панели или клавишей `R`. В нём показано количество пикселей до и после операции, доступны пиксели и проценты, связь пропорций, выбор интерполяции и подсказка по алгоритму. Допустимый размер стороны составляет от 1 до 16 384 px, общий размер ограничен 64 мегапикселями. После подтверждения создаётся новый массив пикселей, а исходный файл в памяти не изменяется во время расчёта.

## Фильтрация

Инструмент открывается кнопкой на левой панели или клавишей `F`. В диалоге доступны девять полей ядра 3×3, выбор каналов, стратегия заполнения края, предпросмотр, сброс, отмена и применение. Предустановлены тождественное ядро, повышение резкости, размытие по Гауссу, прямоугольное размытие и два ядра оператора Прюитта. Значения любого ядра можно изменить вручную.

Для пикселей за пределами изображения реализованы три стратегии: чёрное заполнение, белое заполнение и копирование ближайшего краевого пикселя. Свёртка применяется только к выбранным каналам, остальные компоненты копируются без изменений. Размер изображения после фильтрации сохраняется.

Дополнительно реализован медианный фильтр 3×3 для удаления импульсного шума. На локальном сервере и хостинге обработка выполняется в Web Worker. Если Worker недоступен, используется асинхронная обработка небольшими блоками строк, поэтому интерфейс продолжает реагировать на действия пользователя.

## Тестовые файлы

В репозитории находятся выданные к заданию примеры:

- `gradient-half-mask.gb7` — 32 × 32, с маской;
- `kapibara-mask.gb7` — 1200 × 1010, с маской;
- `vertical-kapibara.gb7` — 1080 × 1920, без маски.
- `test-images/color-grid.png` — небольшой тест PNG с альфа-каналом;
- `test-images/color-grid.jpg` — небольшой тест JPEG без альфа-канала.

Три примера GB7 доступны прямо на стартовом экране приложения. Для ручной проверки рекомендуется открыть каждый файл, сохранить его во всех трёх форматах и повторно загрузить полученный результат.

Автоматические проверки GB7, каналов, CIELAB, уровней, масштабирования, свёртки, медианы, предустановок и обработки краёв находятся в каталоге [`tests`](./tests/). Всего выполняется 31 проверка.
