# GB7 Studio

Веб-приложение для лабораторных работ №1 «Цифровое представление изображения» и №2 «Цветовые каналы и инструмент „Пипетка“».

## Возможности

- загрузка PNG, JPG/JPEG и учебного формата GrayBit-7;
- отрисовка изображения в HTML5 Canvas без библиотек обработки изображений;
- собственные декодер и кодер GB7 версии 1;
- скачивание текущего изображения в PNG, JPG или GB7;
- двоичная маска прозрачности GB7;
- отображение ширины, высоты, глубины цвета, формата и размера файла;
- панель каналов с миниатюрами и независимым включением компонентов;
- поддержка моделей Gray, Gray + Alpha, RGB и RGBA;
- просмотр альфа-канала как чёрно-белой маски;
- пипетка с координатами пикселя, RGB, HEX и CIELAB;
- масштабирование от 5% до 400%, режимы «вписать» и 1:1;
- drag-and-drop, горячие клавиши `Ctrl/Cmd + O`, `Ctrl/Cmd + S` и `I` для пипетки;
- адаптивный интерфейс для узких и широких экранов.

## Запуск

Проект не требует установки зависимостей. Для работы со своими изображениями можно открыть `index.html` двойным щелчком.

Чтобы встроенные примеры загружались одной кнопкой, запустите локальный статический сервер из корня проекта:

```bash
python3 -m http.server 8080
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Реализация GrayBit-7

Кодек находится в `js/gb7.js`.

- Проверяются сигнатура `47 42 37 1D`, версия, флаги, размеры, резервное поле и длина данных.
- Ширина и высота читаются и записываются в big-endian порядке.
- При декодировании значение `0…127` переводится в `0…255`.
- При кодировании RGB переводится в яркость по формуле Rec. 709: `0.2126R + 0.7152G + 0.0722B`.
- Если есть прозрачные пиксели, устанавливается флаг маски. Альфа `0…127` считается прозрачной, `128…255` — непрозрачной.
- При отсутствии маски старший бит каждого пикселя равен нулю.

PNG и JPEG декодируются и кодируются средствами браузера. Их заголовки читаются отдельно для показа исходной глубины цвета.

## Цветовые каналы

После загрузки исходные RGBA-пиксели один раз копируются в отдельный неизменяемый буфер. Переключение каналов создаёт новый массив для вывода на основной canvas и не меняет оригинал.

- Gray: один канал яркости;
- Gray + Alpha: яркость и прозрачность;
- RGB: красный, зелёный и синий каналы;
- RGBA: RGB и альфа-канал.

Миниатюры отдельных каналов показываются в градациях серого. Если в RGBA или Gray + Alpha оставить только альфа-канал, основной canvas показывает непрозрачную чёрно-белую маску.

## Пипетка и CIELAB

Пипетка включается кнопкой на левой панели или клавишей `I`. Координаты клика пересчитываются из CSS-размера canvas в реальные координаты изображения, поэтому инструмент работает при любом масштабе.

Пипетка читает RGB исходного пикселя. Для перевода sRGB в CIELAB сначала выполняется линеаризация компонентов, затем переход в XYZ с белой точкой D65 и расчёт `L*`, `a*`, `b*`.

## Тестовые файлы

В репозитории находятся выданные к заданию примеры:

- `gradient-half-mask.gb7` — 32 × 32, с маской;
- `kapibara-mask.gb7` — 1200 × 1010, с маской;
- `vertical-kapibara.gb7` — 1080 × 1920, без маски.
- `test-images/color-grid.png` — небольшой тест PNG с альфа-каналом;
- `test-images/color-grid.jpg` — небольшой тест JPEG без альфа-канала.

Три примера GB7 доступны прямо на стартовом экране приложения. Для ручной проверки рекомендуется открыть каждый файл, сохранить его во всех трёх форматах и повторно загрузить полученный результат.

Автоматические проверки GB7, переключения каналов, неизменности оригинала, альфа-маски, преобразования CIELAB и трёх примеров находятся в каталоге [`tests`](./tests/).
